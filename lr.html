Installation Guide

1

Download Plugin

Download the latest version of the AI Image Tagger plugin zip file.

2

Get API Key

Get API keys for your preferred AI provider: Google AI Studio (Gemini), OpenAI Platform (GPT-4V), or install Ollama locally.

3

Install in Lightroom

Add the plugin to Lightroom Classic through File > Plug-in Manager and configure your API key.

4

Start Tagging

Select photos and use Library > Plug-in Extras > Tag Photos with AI to begin automatic tagging.

Release Notes

Version 8.4.0 - My Prompts: User-Defined Prompt Library

LATEST

Released June 14, 2026 - Store and reuse your own custom prompts without copy-pasting.

  • My Prompts dropdown: A new "My Prompts" dropdown appears in Plugin Settings under AI Prompt Customization. It lists all .txt files from the prompts/ folder inside the plugin directory. Select one to instantly load it into the Custom Prompt text area.
  • Open Folder button: Click "Open Folder..." to create the prompts/ folder if it doesn't exist and open it in Finder (macOS) or Explorer (Windows). Drop your .txt prompt files there.
  • No restart required: Just reopen Plugin Settings after adding files and they appear in the list immediately.

Version 8.3.7 - Remove Misleading Batch Size Setting

Released June 14, 2026 - Removed the non-functional Batch Size field and improved Delay Between Requests help text.

  • Batch Size removed: The "Batch Size (1–10 photos per batch)" field was dead code — it was stored in preferences but never read by the processing loop. Removed to avoid confusion. The two settings that actually control throughput are Max Parallel Requests and Delay Between Requests.
  • Better help text: Delay Between Requests now explains its purpose and gives a concrete recommendation for Gemini free tier: 2000ms delay + Max Parallel Requests = 2 for reliable processing of any number of photos.

Version 8.3.6 - Danish Language Support

Released June 14, 2026 - Full Danish UI translation and Danish AI response language option.

  • Danish UI: All menus, dialogs, settings panels, and status messages are now available in Danish (da).
  • Danish AI responses: Danish added to the AI Response Language dropdown so AI-generated titles, captions, keywords, and descriptions can be returned in Danish.

Version 8.3.5 - Results Dialog Layout Fix

Released May 8, 2026 - Results dialog now properly resizes horizontally and vertically, and opens wider by default.

  • Dialog resizing: Both metadata columns now fill and resize correctly when you drag the dialog wider — no more clipped right column.

  • Wider default: The dialog opens at ~900px wide by default so both columns are fully visible without resizing.
  • Larger text fields: Caption, Headline, Instructions, Copyright, and Location fields are taller for easier reading and editing.

Version 8.3.4 - Keyword Decoration Crash Fix

Released May 8, 2026 - Fixes a crash when keyword decoration is set to Parent Keyword with a blank value.

The parent/prefix/suffix value is now validated and trimmed before use, and keyword creation falls back gracefully when the parent value is blank.
